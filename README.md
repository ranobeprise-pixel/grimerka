# Гримёрка

Здесь надевают маску перед выходом в ленту. Персонаж и визуальный код блога, школа блогинга из восьми модулей, библиотека приёмов и банк идей и сценариев.

Открой в Safari → «Поделиться» → «На экран Домой». Записи хранятся только на твоём телефоне, резервная копия — во вкладке «Идеи».

Шрифты: Unbounded, Caveat, Golos Text, IBM Plex Mono — SIL Open Font License.
